# Rock paper scissor

A little project so I can play rock paper scissor with my laptop when I am bored.

1. Recognize gestures

* convnext (fine tuned)
* CNN (trained self)
* mediapipe

2. Recognize when game starts
3. strategy for rock paper scissor (random)
